What does this IP tell me?

This is the address seen by the IP check service. With a VPN or proxy, it may be that service's exit address. It does not identify a person or reveal an exact home address.

How is this free?

GitHub Pages hosts this static website. The checks use ipify's free public IP API, with no API key. Availability depends on your network and the API.

Where does my data go?

Loading the site connects to GitHub Pages. Clicking Find my IP or Refresh sends requests to api64.ipify.org, api.ipify.org, and api6.ipify.org, which see your connection's public IP. This app has no analytics, database, cookies, or stored IP history. Local inspection sends no requests.
